# 周末出逃计划

Node.js 22.13+（推荐 Node.js 24 LTS）。首次启动 `npm ci`，然后 `npm start`，访问 http://127.0.0.1:4173/ 。`npm test` 验证核心逻辑。

## 已实现

- 目录收录 52 个国内周末旅行目的地。每张卡片展示当地实景照，可按城市名、地标和机场代码搜索。无对应机场的城市提供转乘提示。
- 缓存以当前目的地清单为准。新增可以查机票的目的地会自动补采，移除的航线会清理批量和临时报价缓存。每天北京时间 12:00 批量采集六个出发城市到当前可查目的地的航班，扣除同城航线。批量采集范围是本月与下月尚未过去的周五、周六去程和对应周日返程。遇到飞猪限流会暂停，稍后继续补采。也可按城市搜索，手动补查指定目的地。
- 通过官方 @fly-ai/flyai-cli 查询真实票价。点击具体方案的「去飞猪选票价套餐」后，核对两段航班并打开该组合的官方往返链接。无法取得匹配链接时，直接打开飞猪同路线、同日期的往返搜索。
- 可选周五或周六出发，周日返回。周五默认 21:00 后起飞，周六默认 07:00 后起飞，周日默认 18:00 后返程。起飞时间可修改；当前仅支持成人1人、经济舱、直飞。
- 核对日期、城市和去返机场代码；排除多航段、经停及周一到达的返程；从本次返回候选中组合往返，不保证全航班最低。
- FlyAI 返回票面价。机建与燃油按国内普通成人标准逐段估算，方案详情显示费用明细。未能估算的航班标为“总价待核实”。页面用两段单程票估算往返总价，成交价以飞猪往返订单为准。
- 打开或刷新页面时展示全部目的地的照片和介绍。点击查询后，按所选日期、去返最早起飞时间和预算筛选报价，默认预算为 1200 元。
- 手动查询时，处于定期采集范围内但尚无缓存的航段，以及超出该范围的周末，都会按需调用 FlyAI。相同航线、日期和起飞时间筛选复用临时缓存，报价在下一次北京时间 12:00 到期并清理。查询后切换条件时，预览只读批量缓存。
- 交通方式可切换为「高铁 / 动车」。手动查询铁路 12306，展示成人二等座有余票的直达往返选项，按两程票价总和与最早发车时间筛选。仅查询预售期内日期；点击方案可打开 12306 核对价格及余票。
- 默认同一次查询并排比较飞机和高铁，也可只查其中一种。任一交通方式先返回即可查看；超预算会显示最低已知报价及差额，暂未拿到报价时可单城补查。其余目的地收在报价状态折叠区，仍可查看攻略。
- 所有目的地照片的拍摄对象、作者和使用许可见 [照片来源](dist/images/CREDITS.md)。
- 52 个目的地的「城市详情 → 游玩」均提供两天一夜攻略，可切换休闲版和特种兵版。行程包含景点、美食、住宿区域、接驳与返程安排，所列车程为规划估算。
- 攻略的「周末花费参考」可编辑住宿、餐饮、市内交通和景点门票预留金额。选定班次后合计其往返报价；暂无报价时只算本地开销。点击站间距离可在百度地图查看线路，起点或终点需现场选择的段落可打开地标定位。
- 报价卡显示预计到市区时间、周日抵达出发城市的时间和预计可玩时间。支持设置周日最晚抵达时间，并按可玩时间排序。选择具体往返班次后，攻略按预计到市区和离开市区的时间缩短行程。
- 可玩时间按周六、周日 09:00 至 21:00 内的空档估算，扣除进出机场或车站、接驳和返程提前到场时间。已配置的机场或车站使用单独估算，其余站点使用通用估算。景区或离岛交通需另算。
- 每个结果保留班次号、机场或车站、时间和采集时间。SQLite 按单段保存报价，高铁余票缓存两分钟，批量机票超过 24 小时标记为旧报价。采集失败时保留同日期已有机票数据。
- 飞猪请求启动间隔至少 1.8 秒。可收藏目的地，航线暂无缓存时会显示提示。

## 费用标准

- 机建按国内普通成人每航段 50 元估算，依据自 2012-04-01 实施的[财政部民航发展基金办法](https://m.mof.gov.cn/zcfb/201203/t20120329_638923.htm)。支线等适用减免时以实际购票金额为准。
- 按预计出票日（查询当天，北京时间）选用已核对的标准。自 2026-11-05 起，800 公里及以内估算 80 元，超过 800 公里估算 140 元，依据[东航公告](https://global.ceair.com/global/static/Announcement/AnnouncementMessage/notices/202611/t20261104_30653.html)及[海航公告](https://www.hainanairlines.com/HUPortal/dyn/portal/DisplayPage?COUNTRY_SITE=SA&LANGUAGE=US&NEWS_CATEGORY=218&PAGE=NEWS&SITE=CBHZCBHZ)。标准于 2026-11-18 核对，后续调整需更新 `fees.mjs`。
- 距离使用实际起降机场的经纬度计算球面直线距离，参考 [OurAirports 公共领域机场数据](https://ourairports.com/data/)。靠近 800 公里分界时，估算档位可能和航司计费里程不同。最终以购票平台支付页为准。

## 运行形态

SQLite 数据库默认在 `.fare-cache/weekend.sqlite`，可用 `WEEKEND_DATABASE_PATH` 指定路径。首次启动自动导入旧 `.fare-cache/flights.json` 和临时缓存，保留原文件。目的地和攻略由项目内的数据初始化，数据库同时保存批次进度、失败及限流记录。网页和小程序可共用 `GET /api/destinations`、`GET /api/guides/:id`、`POST /api/search` 和 `GET /api/health`。

实时采集在本机 Node 服务运行，127.0.0.1 仅允许本机访问。云端静态页面无法执行 CLI，会显示采集服务未连接，不显示演示报价。不要把需要本地运行的采集能力误认为云端已接通。

## 实测与限制

2026-11-17/18：官方 CLI 免 Key 试用返回深圳→重庆具体航班及票价。网页端8个目的地完整批次返回海口、昆明的往返票面组合；部分目的地返回失败或HTTP429，不能承诺全量覆盖或稳定可用率。已加入节流，但尚未完成长期稳定性验证。

FlyAI 系统提示当前为体验模式，部分结果可能受限。未注册账号、申请或配置正式 Key；没有新增付费服务。实际价格、余票、税费、优惠资格和退改条件以飞猪购买页为准。
