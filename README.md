# 周末出逃 · FlyAI 票价缓存

Node.js 22+。首次启动 `npm ci`，然后 `npm start`，访问 http://127.0.0.1:4173/ 。`npm test` 验证核心逻辑。

## 已实现

- 每天北京时间 12:00 批量采集六个出发城市和八个候选目的地之间的航班，扣除同城航线。范围是本月与下月所有尚未过去的周五、周六去程，以及对应周日返程；月末出发的返程可跨月。查询只读取本地缓存，采集期间可使用已写入的报价。首次运行会启动初次采集；若中午服务未运行，启动后会补采集当天批次。
- 通过官方 @fly-ai/flyai-cli 查询真实票价。点击具体方案的「去飞猪选票价套餐」后，核对两段航班并打开该组合的官方往返链接。无法取得匹配链接时，直接打开飞猪同路线、同日期的往返搜索。
- 可选周五或周六出发，周日返回。默认去程 21:00 起飞或更晚，返程 18:00 起飞或更晚，两项时间可修改；当前仅支持成人1人、经济舱、直飞。
- 核对日期、城市和去返机场代码；排除多航段、经停及周一到达的返程；从本次返回候选中组合往返，不保证全航班最低。
- FlyAI 返回票面价。机建与燃油按国内普通成人标准逐段估算，方案详情显示费用明细。未能估算的航班标为“总价待核实”。页面用两段单程票估算往返总价，成交价以飞猪往返订单为准。
- 打开或刷新页面时按所选出发地和日期的往返含费总价从低到高展示全部目的地，暂无报价的排在最后。预算默认 1200 元，点击查询才应用预算和去返起飞时间。
- 手动查询时，处于定期采集范围内但尚无缓存的航段，以及超出该范围的周末，都会按需调用 FlyAI。相同航线、日期和起飞时间筛选复用临时缓存，报价在下一次北京时间 12:00 到期并清理。首屏预览只读批量缓存。
- 目的地卡片展示城市代表场景的实景照片，并附一句便于识别的说明。来源和授权见 [照片来源](dist/images/CREDITS.md)。
- 每个结果保留航班号、机场、时间和采集时间；超过 24 小时标记为旧报价。缓存路径为 `.fare-cache/flights.json`，重启后继续使用；当日某个查询失败时保留同日期已有采集数据。浏览器也保留上次有结果的查询。
- 飞猪请求启动间隔至少 1.8 秒。可收藏目的地，航线暂无缓存时会显示提示。


## 费用标准

- 机建按国内普通成人每航段 50 元估算，依据自 2012-04-01 实施的[财政部民航发展基金办法](https://m.mof.gov.cn/zcfb/201203/t20120329_638923.htm)。支线等适用减免时以实际购票金额为准。
- 按预计出票日（查询当天，北京时间）选用已核对的标准。自 2026-11-05 起，800 公里及以内估算 80 元，超过 800 公里估算 140 元，依据[东航公告](https://global.ceair.com/global/static/Announcement/AnnouncementMessage/notices/202611/t20261104_30653.html)及[海航公告](https://www.hainanairlines.com/HUPortal/dyn/portal/DisplayPage?COUNTRY_SITE=SA&LANGUAGE=US&NEWS_CATEGORY=218&PAGE=NEWS&SITE=CBHZCBHZ)。标准于 2026-11-18 核对，后续调整需更新 `fees.mjs`。
- 距离使用实际起降机场的经纬度计算球面直线距离，参考 [OurAirports 公共领域机场数据](https://ourairports.com/data/)。靠近 800 公里分界时，估算档位可能和航司计费里程不同。最终以购票平台支付页为准。

## 运行形态

实时采集在本机 Node 服务运行，127.0.0.1 仅允许本机访问。云端静态页面无法执行 CLI，会显示采集服务未连接，不显示演示报价。不要把需要本地运行的采集能力误认为云端已接通。

## 实测与限制

2026-11-17/18：官方 CLI 免 Key 试用返回深圳→重庆具体航班及票价。网页端8个目的地完整批次返回海口、昆明的往返票面组合；部分目的地返回失败或HTTP429，不能承诺全量覆盖或稳定可用率。已加入节流，但尚未完成长期稳定性验证。

FlyAI 系统提示当前为体验模式，部分结果可能受限。未注册账号、申请或配置正式 Key；没有新增付费服务。实际价格、余票、税费、优惠资格和退改条件以飞猪购买页为准。
